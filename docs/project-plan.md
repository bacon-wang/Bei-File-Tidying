# 整体项目计划

更新：2026-09-26｜当前版本：0.3.0（GUI 与后端接口迭代）

## 1. 交付目标

围绕“感知目录 → 批量建议 → 确认整理 → 清理空目录 → 可撤销”形成可重复验证的文件整理流程。功能范围见[需求文档](requirements.md)，实现见[架构文档](architecture.md)。

## 2. 阶段与成果

| 阶段 | 状态 | 成果 / 完成门槛 |
| --- | --- | --- |
| M1：整理 MVP | 已实现 | Java 17 / IDEA 启动、根目录感知、递归扫描、AI 建议、确认移动、允许新建分类目录 |
| M2：效率与恢复 | 已实现，基础验证通过 | 深度可配的目录树、批量并发、阶段日志、空目录清理、最近一次撤销 |
| M3：工程交付 | 已完成 | Maven Wrapper、33 项自动化测试、隔离手动样例、GitHub CI、配置与产物排除、四份项目文档 |
| M4：GUI MVP | 本轮实现 | Swing 目录选择、建议预览、执行、撤销和开发者实时日志 |
| M5：后端接口 | 本轮实现 | 无状态 HTTP AI 转发、健康检查、服务端密钥配置；暂不做数据库、账号和用量管理 |
| M6：可靠性加固 | 已修复静态符号链接路径风险，其余 P0 待实施 | 完成下表 P0 项及回归测试 |
| M7：性能与服务兼容 | 两轮已实现并验证 | 本地规则、元数据优先、按需摘要、有限重试、共享预算、文件组与分类缓存；真实规模对比待实施 |
| M8：内容理解 | 待确认范围 | 根据真实分类误差决定是否加入 PDF / Office 文本提取、图片分析 |

“已实现”表示功能存在，不代表异常边界全部覆盖。现有验证为 37 项自动化测试、184 文件合成场景及 4 文件真实 AI 整理 / 撤销；尚未完成约 184 文件真实混合资料的完整验证。

## 3. 下一阶段工作顺序

| 优先级 | 工作项 | 验收门槛 |
| --- | --- | --- |
| P0 | 路径与响应校验 | 已加入符号链接和保留目录检查；继续覆盖并发路径替换、复杂 JSON 及隐藏子目录规则 |
| P0 | 移动与撤销异常处理 | 覆盖未确认、同名冲突、部分失败、历史损坏和修改后的文件；不覆盖、不丢失，剩余项可追踪 |
| P1 | 批量效率与异常回退 | 在真实混合资料上验证 10 / 50 / 184 文件，记录分类质量、耗时、请求数、回退数和有效 token 数 |
| P1 | 文件组规则与缓存 | 保守编号系列及缓存已实现；以混合资料验证组分类准确率，再决定是否扩展非编号文件组 |
| P1 | 深层目录上下文 | 已实现完整索引上的限长名称匹配；后续验证语义匹配准确性及被截断分支的处理 |
| P2 | 内容分析 | 先用误分类样例证明元数据不足，再选择一种文件类型扩展并验证收益 |

## 4. 验证与发布约定

1. 按 P0 → P1 → P2 推进；未确认的功能扩展不提前开发，暂不承诺日期。
2. 缺陷先建立可复现用例，再修复并回归；执行方式见[测试文档](testing.md)。
3. 发布前通过 `clean verify`，并在 `manual-test` 完成一次真实 AI 建议、确认移动和撤销，记录结果及耗时。
4. Git 仅提交源码、文档和可重复样例；密钥、IDE 配置、构建产物及运行历史保持本地。

持续监听、数据库、账号、用量管理和多次历史撤销暂缓。GUI 与无状态后端已进入 MVP。预算和重试已有上限；内容补充仍可能增加小样本请求次数，第三方响应与用量回报存在波动，历史恢复不具备整批事务保证。
