# 需求文档

更新：2026-09-26｜实现基线：0.2.0（分层分类迭代）

## 1. 目标与范围

Bei File Tidying 是面向个人用户的 Java 命令行文件整理助手。用户指定感知根目录和待整理目录，程序参考目录结构生成逐文件建议，经确认后执行，并支持撤销最近一次整理。

- `sense.root`：提供目录结构上下文，也是整理目的地的范围。
- `target.dir`：本次扫描文件的目录，必须是感知根目录的子目录；递归处理其中的文件。
- 分类合理、结构清晰是首要原则；合适时复用已有目录，也允许新建分类目录。
- 本版为手动启动、执行一次的程序；持续监听、GUI、数据库、多次历史撤销暂不纳入范围。

## 3. 约束与当前限制

- Java 17、Maven Wrapper；项目文件路径使用英文，真实密钥、构建产物及操作历史不入库。
- 默认模型为 `gpt-6-luna`，思考强度 `medium`；需使用密钥所属平台的接口地址。
- AI 接收相对路径、扩展名、大小和相关目录索引；文本按需补充。PDF、Office、图片目前只分析文件名及元数据。
- `max.file.mb` 控制是否读取文本内容；超限文件仍可按元数据分类。
- AI 目录索引独立于终端展示深度，优先选择名称相关分支，最多 2,000 字符；检索尚不具备语义理解，隐藏子目录扫描规则仍需完善。
- 路径检查尚未完整覆盖符号链接祖先目录；响应 JSON 严格校验、撤销异常恢复仍需加固。
- 暂无大规模耗时或成功率承诺；自动化覆盖与真实 AI 结果见[测试文档](testing.md)。
